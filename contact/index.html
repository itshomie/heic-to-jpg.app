Contact

Questions, bug reports, and feedback

If something does not work as expected, or if you have a privacy or site question, send a note with the browser and device you used. Please do not attach private photos.

Email

support@heic-to-jpg.app

For bug reports, include the browser name, operating system, approximate file size, and whether the file came from iPhone, iCloud, Photos, or another app.

Before you write

  • Do not email private HEIC files unless we specifically ask for a sample.
  • Try another browser if a file fails to decode; HEIC support can vary by device.
  • Keep the original HEIC file if metadata or Live Photo details matter to you.

Response scope

heic-to-jpg.app is a focused web utility, so support is limited to the site itself: file selection, local conversion, download behavior, browser compatibility, privacy questions, and corrections to the written guides.
